# VoiceOver checklist for Memory Studio (S7)

Automated checks can't tell whether Studio is actually usable with a screen reader. This walk-through covers what was added from S2 to S6; the R6 checklist ([voiceover-checklist.md](../r6/voiceover-checklist.md)) still covers the basics. It takes about 20–30 minutes.

**Setup**
- Use a folder of a few test photos, with at least five marked as favorites.
- Turn VoiceOver on and off with **⌘ F5**.
- Move with **VO = Control + Option**: **VO + →/←** moves item by item, **VO + Space** activates, and **Tab** moves between controls.

For each step, note **pass**, or what was confusing, missing or wrong. Note the exact words VoiceOver said if they didn't make sense.

## 1. Picking a layout
- [ ] In Favorites, the filters ("Show", "Style") and "Size for the new project" are announced with their choices.
- [ ] Each layout button says its name and how many photos it takes ("Postcards (select 2)"), and whether it's dimmed.
- [ ] The groups are announced by name ("Playful quartets", "Seamless carousels", "My templates").

## 2. Quick edits and captions
- [ ] The preview is announced with its layout, shape, background and any caption.
- [ ] A caption box is announced by its label ("Note"). Return adds a line break, and a missing character (♡) is explained.
- [ ] Changing a colour, a slider or a size announces what changed ("Margin changed. All changes saved.").
- [ ] Undo and Redo are reachable and say what they undo.

## 3. Customize
- [ ] "Arrange photo 1" is announced, with the hint that arrow keys move the photo.
- [ ] Arrow keys and Shift + arrow keys nudge the photo, and the change is announced.
- [ ] The Left, Top, Width, Height, Angle and Rounded corners fields are announced with their values.
- [ ] Flip, Lock, Bring forward, Send back, Bring to front and Send to back are announced, and dimmed when they can't apply.
- [ ] Hide a photo: "Hidden photos (1)" appears and "Show photo 1" is reachable.
- [ ] Take a photo out: the strip announces "empty place", and Export mentions the empty place.
- [ ] Add a place and remove a place: "Removed places (1)" appears, with "Restore place N".
- [ ] Save as my template: the name field is labelled, and the result is announced.

## 4. Seamless carousels and the swipe preview
- [ ] A seamless design's preview says how many slides it has.
- [ ] "Where photos meet a slide edge" is read, with each note in plain words.
- [ ] "Preview the swipe" opens the swipe preview. Side by side, the row is announced ("All 3 slides side by side") and can be scrolled with the arrow keys.
- [ ] One at a time: "Slide 1 of 3" is announced, Previous and Next work, and the arrow keys move between slides.

## 5. Export
- [ ] The Export section says the size, the number of files, and any empty places.
- [ ] "Also save the whole design as one wide file" is announced as a checkbox (seamless carousels only).
- [ ] Progress and the result are announced, and "Show in Finder" works.
